# User Stories and User Characteristics

## Student

Students have varied technical experience and use mobile or desktop browsers. Journeys shall be responsive, keyboard accessible, and understandable without colour alone.

| **ID** | **User story** |
|---|---|
| **US-1** | As a student, I want to register and sign in so that I can use my personal workspace. |
| **US-2** | As a student, I want to select a university and apply for a role so that I can access the correct academic data. |
| **US-3** | As a student, I want to browse courses and modules so that I can identify relevant academic data. |
| **US-4** | As a student, I want to create and style personal modules so that I can represent data not supplied by my university. |
| **US-5** | As a student, I want to create and edit personal events so that my timetable includes private commitments. |
| **US-6** | As a student, I want to manage named timetables and their events so that I can maintain different schedules. |
| **US-7** | As a student, I want to import a supported University of Pretoria timetable PDF so that I do not re-enter academic events. |
| **US-8** | As a student, I want import progress and useful errors so that I can recover from failure. |
| **US-9** | As a student, I want a solver to return a conflict-free or clearly labelled best-effort timetable so that I can choose a useful schedule. |
| **US-10** | As a student, I want to record attendance by date so that I can track attended and missed events. |
| **US-11** | As a student, I want to download my timetable as an iCalendar file so that I can import it into another calendar application. |

## University Administrator

University administrators manage institutional records and role applications. Forms shall provide clear validation, searchable lists, and explicit state changes.

| **ID** | **User story** |
|---|---|
| **US-12** | As a university administrator, I want to manage courses, modules, groupings, and events so that academic data remains current. |
| **US-13** | As a university administrator, I want to review university role applications so that university access is controlled. |
| **US-14** | As a university administrator, I want to approve imported modules and events so that unverified parser output becomes trusted academic data. |

## System Administrator

System administrators manage platform identities and universities. Privileged actions shall require the system-administrator role.

| **ID** | **User story** |
|---|---|
| **US-15** | As a system administrator, I want to create and update user accounts so that platform access can be managed. |
| **US-16** | As a system administrator, I want to ban or impersonate an account so that support and abuse cases can be handled. |
| **US-17** | As a system administrator, I want to manage universities so that supported institutions remain current. |

## Future Users and Journeys

- University analytics and venue-planning workflows.
- Tyto simulation workflows.
- External calendar provider integration.
