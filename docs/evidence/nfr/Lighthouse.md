# Lighthouse Accessibility Reports

NFR-Acc-1 requires an Accessibility score above 90 for each page. The page URL and score appear in each report. The audit covers the accessibility category only. The Event Management view uses `/module-management?tab=events`, while the module view uses `/module-management?tab=modules`.
